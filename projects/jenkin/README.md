# Z:DEV:GRAPH

## Gettings started

Requirements: python, uv.

Steps:
1. Clone this repo and initialize data from the root (see `init.sh` util)
2. Install dependencies: `uv sync`
3. Run the script: `uv run static.py`

Output example:

```
Found 56058 commits by 1226 developers in 91 repositories from 2013-06-24 to 2026-07-20 in 15.5s
Graph with 893 nodes and 44388 edges (19 groups, 0 isolated nodes) in zcash_irondevs_static.png
```
